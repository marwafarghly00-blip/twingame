# 🎀 Cartoon Twin AI

Cartoon Twin AI is a fun interactive web game that simulates an AI face-scanning experience and matches the user with a random cartoon character.

The game runs directly in the browser using HTML, CSS, and JavaScript, with a neon pastel design and animated scanning effect.

---

## ✨ Features

- 🎥 Camera activation (browser-based)
- 🟣 Neon fake AI scanning animation
- 🎰 Fast character shuffle effect
- 🎯 Random cartoon twin result
- 🔄 Restart button to play again
- 💖 Neon pink pastel UI design
- 📱 Works on laptop and mobile browsers

---

## 🎮 How It Works

1. Open the game in your browser  
2. Allow camera access  
3. A scanning animation starts automatically  
4. Characters shuffle quickly like a slot machine 🎰  
5. The game stops and shows your cartoon twin  
6. Click "Start Again" to replay
